# Apple-inspired web design

Use this skill for Apple-inspired web styling. A request for a landing page, form, dark mode, or responsive layout alone does not choose an Apple style.

- Follow the user's visual reference and the current project tokens, components, and layout. Example Apple colors and effects are optional inspirations, not replacements for the project design.
- Use clear hierarchy, readable typography, consistent spacing, and restrained decoration. Keep controls recognizable and content legible.
- Reuse the project's fonts and icon library. For system fonts, include platform fallbacks; do not assume Apple fonts or SF Symbols are available on Windows or the web.
- Add blur, glass, gradients, or animations only when they fit the selected design. Respect reduced-motion settings, keyboard focus, contrast, and touch targets.
- Implement the requested states and responsive behavior. Add a dark theme only when requested or already part of the project contract.
- For implementation requests, edit the existing components. For design advice or critique, explain the relevant choices without generating an unsolicited application or complete code sample.
- Verify affected layouts and interactions at relevant viewport sizes. Report unavailable device checks accurately.

This installation has no bundled templates or reference files. Do not search for the retired `.shared/skills/apple-design/` tree.

For platform-specific requirements, consult the current [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/).
